## What's fixed

**Radio now stops automatically before a normal FPP playlist opens music or video.** The 1.2.3 silent-sequence change still left the handoff to a once-a-minute monitor and its starting grace, allowing radio and show audio to overlap. This release uses FPP's native media-open callback instead.

- Works without the radio page or Status page being open, including when the show starts just after radio starts.
- Stops radio and cancels pending Seek/recovery before the playlist track begins. FPP media-close notifications and lights-only `.fseq` sequences leave radio alone.
- Respects **Protect FPP media playback**. Keep that setting enabled for automatic handoff.
- FPP 10.4 Plugin Manager loads the new callback when it reloads this plugin after Update. The normal Update needs no controller reboot, FPPD restart or radio-service restart. The update log should say **Reloaded After-Show-Hours-Radio in FPPD; no restart needed.**
- Same install link, stations, presets and schedules. No FPP core edits, new daemon, extra polling loop or external network requests.

The existing monitor remains a fallback for independently launched background command streams that do not emit a native media-open callback. Scheduled Stop commands still work for an explicit handoff before any show command. If FPP reports that it could not reload the plugin, follow its Restart FPPD banner when idle to finish registering the callback.

## Install on FPP 10.4

**Copy this install link into FPP:**

```text
https://raw.githubusercontent.com/ravenridgelights-turtle/After-Show-Hours-Radio/main/pluginInfo.json
```

1. Open **Content Setup → Plugin Manager** in FPP.
2. Paste the link above into the field labeled **Find a Plugin, or paste its GitHub or pluginInfo.json URL**. If URL installation is hidden, temporarily change FPP's **UI Level** to **Developer**.
3. Select **After Show Hours Radio**, review FPP's plugin/dependency information and choose **Install**. Wait for installation to finish.
4. When your show is idle, use FPP's **Restart FPPD** banner once to register the radio's new FPP commands. **A controller reboot is not required.**
5. Open **Content Setup → After Show Hours Radio**, or choose **Open** on its Plugin Manager card. Look for the orange boombox icon.

The [repository URL](https://github.com/ravenridgelights-turtle/After-Show-Hours-Radio) also works in FPP's URL field. You do not need to download or upload GitHub's source ZIP files.

**Already installed?** Open **Plugin Manager**, check for updates on **After Show Hours Radio**, and click **Update**. Refresh the radio and Status pages afterward. The radio page should show **RADIO 1.2.4**. Keep the same installation link; no reinstall or FPPD restart is needed for this update. Saved stations, preset assignments and schedules stay in place.

**Moving from the original After Hours plugin?** Stop it and remove its old scheduled Start commands first. On this plugin's first install, valid internet stations are copied from the original plugin's settings if present. Set up the new presets and schedule commands below. Only run one radio at a time; you can uninstall the original afterward.

## Find and save stations

1. Open **Find stations** and select a **Station source**.
2. For **Internet-Radio.com · Search any music or station**, enter a station name or a style such as `classic rock`, `jazz`, `country` or `oldies`, then choose **Search source**. The search is for everyday music as well as holiday stations.
3. For **Radio Browser · Search any music or station**, select **Station name** or **Genre / tag**, enter your search, and choose **Search source**.
4. For a preset directory such as Christmas, Halloween or 181.FM, choose **Load stations**. **Internet-Radio.com · Browse a genre** accepts a genre directly.
5. Choose **Save station** to keep a result, or **Play** to save it and tune in. **Filter these results** filters the loaded list locally. **Load next page** loads only the next page when available.

Sources include Radio Browser, 181.FM, Internet-Radio.com, Halloweenradio.net and StreamURL. Directory access depends on the provider; a blocked or changed site may be unavailable.

**Already know a stream URL?** Under **Add a known station** in Find stations, enter its name and direct `http://` or `https://` audio URL, then choose **Save station** or **Save & play**. A normal station website address is usually not an audio stream. **Saved stations → Add station** also lets you set category, favorite and station volume.

Requests are made only when you ask, one at a time and at least 10 seconds apart. Directory results are cached for six hours. There is no background crawling or testing of every station. Wait for the displayed cooldown before refreshing a source again.

## Use it like a radio

| Control | What it does |
|---|---|
| **Play** beside a station or an assigned preset | Tunes directly; you do not have to press Stop first |
| **Next / Previous** | Moves through enabled saved stations in their saved order, wrapping at either end |
| **Seek forward / backward** | Checks up to five enabled saved stations, one at a time, and tunes the first that returns an audio sample |
| **Stop** | Stops playback and cancels pending Seek/recovery |
| **Volume / Mute** | Changes the radio's volume; FPP's show volume is separate |
| **Sleep** | Stops after the selected time, with roughly one-minute precision |

Use the **Enabled** checkbox in Saved stations to include a station in Next, Previous, Seek and automatic recovery. Use the up/down arrows to set the order. Direct Play and presets can still tune a disabled station. Seek searches your saved stations; it does not search the whole internet. A new live stream may need a short moment to connect and buffer.

## Set up pages of 12 presets

1. Save the stations you want to use.
2. Choose a **Page** above the preset buttons. **Christmas**, **Halloween** and **Everyday** are created initially.
3. Tap an empty preset, select a saved station and choose **Save preset**.
4. To change an assigned button, choose **Edit presets**, tap its number, select a different station or the empty choice, and save. Choose **Done editing** to return to tuning.
5. Choose **+ New page** to add another named group of 12. **Rename** changes its name; **Remove page** removes its assignments while keeping the saved stations. Up to 64 pages are supported.
6. Select a page and tap an assigned number to tune it immediately.

If a schedule uses a page name, update that schedule when you rename the page.

## See and control radio on FPP Status

While the radio is playing and FPP is **idle or running a confirmed lights-only sequence**, **Status - Player Mode** shows the station name, available artist/song metadata, radio volume and bitrate. Compact FPP-style **Previous**, **Stop**, **Next**, preset-page selection and numbered **1–12** buttons work there too. Empty presets are disabled.

The panel hides when the radio stops or FPP starts media or another protected activity. During a lights-only sequence, the native sequence name and player status remain unchanged. FPP's native show/song status stays in control during shows. Status-page page selection applies only to that browser tab. Use **Radio controls** to open the plugin for editing presets or settings.

## Start and stop around shows

After the initial **Restart FPPD**, these commands appear in FPP's command picker:

| FPP command | Use |
|---|---|
| **After Show Hours Radio - Stop** | Stop the radio before a show |
| **After Show Hours Radio - Start** | Resume the last enabled station, or the first enabled station |
| **After Show Hours Radio - Play Preset** | Enter preset **1–12** and an optional page name, for example **3**, **Christmas** |
| **After Show Hours Radio - Next Station** | Tune the next enabled saved station |
| **After Show Hours Radio - Previous Station** | Tune the previous enabled saved station |

For a show playlist:

1. In **Lead In**, add **FPP Command → After Show Hours Radio - Stop**.
2. Add a **1-second Pause** immediately after it.
3. Put the normal show items in the playlist.
4. In **Lead Out**, add **After Show Hours Radio - Start**, or **Play Preset** with the number and page you want after the show.
5. Schedule that playlist normally. You can also schedule the radio commands directly in FPP Scheduler.

Keep **Settings & schedules → Protect FPP media playback** enabled. It allows radio with a confirmed lights-only sequence while blocking manual tuning over FPP music/video and active media slots. Paused playlists, tests, commands/scripts, transitions and unverified activity stay protected. For normal playlist tracks, the native media-open callback stops protected radio before the track opens, without waiting for the monitor. The monitor remains a fallback for other media paths or unavailable FPP status. Your explicit Lead In Stop command remains available for a handoff before any show command. Scheduled Start/Play Preset commands remain trusted so they can run in Lead Out; place them after the show's media items.

### Radio during static-only animation

Start the lights-only `.fseq`, then press radio **Play** or a preset. Keep **Protect FPP media playback** enabled; no override is needed. You can also put **After Show Hours Radio - Start** or **Play Preset** at the beginning of a static-only playlist. If that playlist already contains a radio **Stop** command, it will still stop radio: remove that Stop only from a static-only playlist where you want music. Keep the Stop/Pause lead-in for musical shows.

Radio playback does not automatically resume after a reboot. Add a scheduled Start or Play Preset command if you want it to resume at a particular time.

## Settings, backups and help

- **Settings & schedules** contains show protection, stalled-stream recovery, starting volume and the schedule reminders.
- **Export backup** saves stations and all named preset pages. **Import backup** merges stations by exact URL and fills empty preset slots without replacing existing assignments.
- **Update** and **Reinstall** keep settings. A real **Uninstall** removes this edition's settings/cache, so export a backup first.
- If you change FPP's audio output/group, use **Reinstall** to refresh the plugin's audio connection.
- If commands are missing after a first install, use **Restart FPPD** when idle. If a station will not play, try another station or check that its URL is a direct audio stream.
